The same process, explained — for the first time, or when something goes wrong. Targets: under 2 MB (3 MB at most, the CMS refuses over 8 MB), about 50k–150k triangles, textures 2048px or smaller.

Before you start

Work on a copy of the Rhino file (File ▸ Save As…, e.g. oak-sideboard-web.3dm), so nothing you delete for the web is lost from the real project.

1. Clean up the model

Everything in the file can end up in the export, and every hidden part makes it heavier. Delete or hide:

  • construction lines, curves, 2D linework, dimensions, text and hatches;
  • site context, floors, walls or people that aren't part of the piece;
  • internal parts nobody will ever see (screws, dowels, hidden joinery), unless they matter to the design.

A 3D model of a chair should be only the chair. The site adds a soft shadow underneath, so you don't need a floor.

2. Keep materials simple

The web viewer understands colour, roughness and metal, not Rhino's full render materials. Either give each part a simple material (a wood, a fabric, a metal — fewer than about 10 in total), or skip materials and just set each object's display colour; the export turns it into a plain material. Image textures (wood grain photos etc.) work but add size; keep them at 2048px or smaller.

3. Set how detailed the mesh is

Rhino turns surfaces into triangles when it exports, and these settings decide how many:

  1. File ▸ Properties ▸ Mesh.
  2. Choose Jagged and faster.
  3. Tick Simple planes (flat faces get as few triangles as possible).
  4. If curved edges later look faceted (step 6), come back, choose Custom and move Density up a little. Small steps — each one can double the file size.

To see the count, select the objects and run the PolygonCount command. Aim for about 50,000–150,000.

4. Export

  1. Select only the objects that make up the piece.
  2. File ▸ Export Selected.
  3. File type: glTF Binary (*.glb).
  4. Name it with lowercase letters and hyphens, no spaces: oak-sideboard.glb.

5. Export options

In the dialog that appears, make sure these are on:

  • ✅ Map Rhino Z to glTF Y — keeps the model the right way up.
  • ✅ Export materials
  • ✅ Use display color for objects with no material set
  • ✅ Use Draco compression — off by default; this is the one that shrinks the file the most. Leave its level and the numbers below it as they are.

Units don't matter: the export converts them to metres automatically.

6. Check the file

  • Size: in Finder, select the file and press ⌘I (Get Info). Under 2 MB is ideal, up to 3 MB is fine, over 8 MB is refused.
  • Look: drag the file into modelviewer.dev/editor. Check it is the right way up, the colours look right and curves aren't faceted.

7. If it's too big

Try in this order:

  1. Go back to step 1 — something hidden is often still in there.
  2. Step 3 — make sure it's Jagged and faster, or lower Density.
  3. For objects that are already meshes, Rhino's ReduceMesh command cuts their triangle count (try 50%).
  4. Shrink image textures to 1024px.
  5. Still too big: send the .glb to the developer, who can compress it further.

8. Prepare the Main image

It is shown while the model loads, on phones without 3D support, and as the home-page tile — so it should look like the model from the angle you'll choose in step 10. A Rhino render works, or a viewport capture (ViewCaptureToFile). No render? In the modelviewer.dev editor, turn the model to a nice angle and click POSTER to download a still.

9. Upload it here

  1. Set the Main image (step 8) if it isn't there yet.
  2. 3D model (optional) → Browse → Upload → choose the .glb → Insert.
  3. 3D model description: one sentence describing the object for visitors who use screen readers, e.g. "Oak sideboard with three doors and turned legs".

10. Choose the starting angle

The Preview pane on the right shows the model as visitors will see it.

  1. Drag to turn it, scroll to zoom, until it shows the view you want people to see first.
  2. Click Copy under the model (if nothing is copied, the value is highlighted — press ⌘C).
  3. Click into 3D model starting angle and paste (⌘V). The preview jumps to that view, so you can check it. Reset goes back to the saved angle.

Leave the field empty and visitors get a front three-quarter view.

11. Save and check

Click Save. The site rebuilds and the page is live in about 2 minutes. Open it on your phone too: the main image should appear first, then the model fades in.

Common problems

  • Upside down or lying on its side: re-export with Map Rhino Z to glTF Y ticked.
  • Everything is grey or white: materials didn't come through — tick Export materials and Use display color…, or switch the parts to simple materials / display colours.
  • Curves look faceted: raise Density slightly in step 3.
  • Upload fails or is refused: the file is over 8 MB, or the connection dropped during upload. Make it smaller (step 7) and try again.
  • The model looks tiny or huge in the preview: that's fine — the viewer frames it automatically. Only the starting angle's zoom is affected; set it again in step 10.
